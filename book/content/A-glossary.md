# 附录 A　术语表

> 按"所属层次"分组，便于定位一个术语在整个系统中的位置。定义力求一句话说清"它解决什么问题"，而不只是"它是什么"。

## 约束层

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 上下文窗口 | Context Window | 一次调用中"输入 + 输出"的 token 总量上限，是系统中唯一的共享内存预算 |
| 上下文预算 | Context Budget | 对上下文窗口的显式分配方案，规定每类内容可占用的上限 |
| Token 计数 | Token Counting | 把文本换算为模型计量单位的过程，是发送前预算核算的前提 |
| 无状态 | Statelessness | 模型不记忆上一次调用，因此所有记忆必须外置并在每次请求时重新注入 |
| 概率性 | Stochasticity | 相同输入不保证相同输出，因此契约必须运行时强制、失败必须统计评估 |
| 静默错误 | Silent Failure | 格式合法、执行成功但结果错误的故障形态，是这类系统最难排查的问题 |
| 成本三要素 | Cost Triad | token、延迟、并发额度三者互相约束，是预算设计的三个维度 |
| 失败率累积 | Compounding Failure | 单步成功率在长链路上呈乘性衰减，因此减少步数收益常大于优化单步 |

## 抽象与协议层

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| Runnable | Runnable | 统一执行协议，规定所有组件实现同一输入输出契约与执行模式 |
| 执行模式 | Execution Modes | 单次、批量、流式、异步流式四种调用形态，覆盖结果数量与到达方式两个正交维度 |
| 组合子 | Combinator | 构造执行结构的基本元件：顺序、并行、分支、透传、动态求值、装饰 |
| 声明式编排 | Declarative Composition | 描述组件之间的关联而非步骤顺序，使结构成为可被引擎消费的一等对象 |
| 流式传播 | Streaming Propagation | 每个组件都支持"流进流出"时，整条链路可端到端增量转发 |
| 回退 | Fallback | 执行失败时改用替代实现的机制，语义是整段替换而非从中断处续接 |
| 装饰 | Decoration | 给组件附加回退、重试、配置等执行语义而不改变数据形状 |
| 回调 | Callback | 协议层固定的生命周期钩子，是观测能力的统一挂点 |
| 消息角色 | Message Roles | 系统、人类、模型、工具四种角色的语义与顺序约束 |
| 工具调用协议 | Tool Calling Protocol | 三段式协议：模型输出结构化意图 → 宿主执行 → 结果回灌 |
| 结构化输出 | Structured Output | 让模型产出程序可用数据的机制，三条路线：提示约束、工具调用借用、受限解码 |
| 能力降级 | Capability Degradation | 目标实现不支持所需能力时的替代策略，原则是差异可感知且可接受才降级 |
| 提示模板 | Prompt Template | 从数据到消息序列的纯函数，要求无副作用、参数有类型、输出形状显式、可组合 |
| 输出解析器 | Output Parser | 三层职责：抽取（宽松）、校验（严格）、修复与升级 |
| 系统边界 | System Boundary | 不确定性进入系统的位置：模型输出、工具结果、外部数据。校验必须在此执行 |
| Schema 契约 | Schema Contract | 结构、行为、语义三层声明，价值在"拒绝非法数据"而非"描述数据" |
| 归约器 | Reducer | 同一状态字段的多份增量如何合并的规则，决定并发安全 |
| MCP | Model Context Protocol | 工具与能力标准化的协议，客户端-服务器结构，按"谁主导"与风险分级划分原语 |
| 能力协商 | Capability Negotiation | 连接时交换双方支持的能力与版本，只使用交集，提供向前兼容 |
| 资源原语 | Resource Primitive | 提供方主导的只读内容暴露方式，与工具相比风险更低 |

## 执行层

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 状态 | State | 图中流动的共享数据，是系统在任一时刻的完整描述与唯一真相来源 |
| 增量更新 | Incremental Update | 节点只返回自己修改的部分，使多来源更新可合并而不丢数据 |
| 通道 | Channel | 状态字段的运行时表现形态，维护当前值、待合并更新与合并规则 |
| 超步 | Super-step | 执行的同步节拍：并行执行节点 → 边界同步 → 统一合并 → 下一轮 |
| 同步边界 | Synchronization Barrier | 一轮结束时的统一对齐点，是可复现性与状态自洽性的来源 |
| 激活集 | Active Set | 某一轮需要执行的节点集合，集合内节点无顺序、可并行 |
| 条件边 | Conditional Edge | 在状态合并后求值、决定下一轮激活集的连接规则 |
| 确定性 | Determinism | 同一检查点重放得到一致结果的性质，来自调度决策的固定与外部交互的记录 |
| 回放 | Replay | 使用记录的外部交互重演执行，与"重跑"（重新计算）相对 |
| BSP | Bulk Synchronous Parallel | 整体同步并行模型，超步调度的理论名称 |
| 终止判据 | Termination Criteria | 显式定义的"什么算完成"，必须包含目标达成、无法完成、约束触顶三类 |
| 进展检测 | Progress Detection | 识别"看起来在动实际在原地打转"的机制：单调性、重复检测、轮间差异 |
| 预算 | Budget | 步数、工具调用次数、token、墙钟时间四类执行约束，超限即中止 |
| 护栏 | Guardrail | 预算型、收敛型、权限型、审批型四类外部约束，不依赖智能体自觉 |

## 持久化与交互层

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| 检查点 | Checkpoint | 执行过程的持久化快照，含状态、执行位置、外部交互记录、版本信息 |
| 线程 | Thread | 串联同一条执行链上所有检查点的标识，定义"一次连续交互"的边界 |
| 时间旅行 | Time Travel | 回到任意历史检查点继续、修正或分叉；能重演决策，不能撤销外部事实 |
| 持久执行 | Durable Execution | 执行可跨进程重启、跨实例接管、跨时间跨度继续的能力 |
| 幂等性 | Idempotency | 重复执行不产生额外外部影响的性质，是重试与恢复的前提 |
| 幂等键 | Idempotency Key | 由业务语义决定的唯一标识，由产生副作用的一侧负责去重 |
| 中断 | Interrupt | 一次有契约的退出与重入，契约规定中断点、保存内容、恢复输入 |
| 硬中断 / 软中断 | Hard / Soft Interrupt | 由外部配置位置触发 vs 由流程内部逻辑触发 |
| 人在回路 | Human-in-the-loop | 把人工决策点嵌入自动化流程，三种模式：审批、编辑、工具确认 |
| 待决问题 | Pending Question | 中断时构造的"我在等什么"的描述，恢复方据此提供输入 |

## 观测与评估层

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| Span | Span | 一次原子操作的记录：标识、父标识、时间、输入输出 |
| Traces | Trace | 一次完整执行的记录，把 Span 按父子关系组织成时间线 |
| 轨迹评估 | Trajectory Evaluation | 过程级评估：步骤合理性、绕路、重复失败、强行结论 |
| 忠实度 | Faithfulness | 回答中的断言能否在给定依据中找到支持，衡量是否"自由发挥" |
| LLM 作为评委 | LLM-as-Judge | 用模型评分的手段，有位置、长度、自我偏好、标准漂移四类偏差，必须校准 |
| 回归集 | Regression Set | 由线上失败转化而来的固定用例集，用于判断改动是改善还是倒退 |
| 灰度 | Canary Release | 按会话粘性分流部分流量到新版本，配套明确的在途任务策略与快速回滚 |

## 五种 Agent Loop 模式

| 术语 | 英文 | 一句话定义 |
|---|---|---|
| ReAct | Reason + Act | 思考与行动交替，把推理显式化影响后续决策 |
| Plan-Execute | Plan and Execute | 先产出结构化的步骤计划再逐步执行，主要风险是计划与执行脱节 |
| Reflexion | Reflexion | 执行后自我批判并带反馈重试，主要风险是轮数失控 |
| Router | Router / Dispatcher | 先分类再分发到不同处理路径，主要风险是分类抖动与缺兜底 |
| 多智能体拓扑 | Multi-agent Topology | 主管、群体、层级三种组织方式，代价是上下文膨胀、信息丢失、延迟累积 |
| 子图 | Subgraph | 可作为整体嵌入更大流程的执行单元，价值在作用域隔离与多实例 |
