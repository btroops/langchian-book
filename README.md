# 智能体运行时原理

> 从 LangChain 到 LangGraph，及可迁移的 Agent 设计法则

一本讲**原理**而不是 API 的技术书。

LangChain / LangGraph 只是某一时刻的一组实现；真正可迁移的资产是它们背后的**运行时原理**。
所以这本书里 **没有一行可以直接运行的代码**——每一章都在回答"为什么必须这样、不这样会怎样"，
并以"离开这套框架，你自己会怎么造"收尾。

## 构建与校验

依赖 Python 3 与 `markdown`：

```bash
pip install markdown

cd book
python check.py     # 规范校验，退出码 0 才算通过
python build.py     # 生成 dist/，输出 "OK  chapters=25  chinese_chars=..."
```

`check.py` 把写作规范里所有"每章必须…"的条目实现成了可执行检查：字数下限、每章有表格 + 图示、
固定结构小节齐全（含已登记的结构例外）、首行标题格式、零可运行代码、代码块语言标记、
内联样式、图示类名白名单、附录条数自洽、章节编号连续、跨章口径一致。

**改稿流程：改 `content/*.md` → 跑 `check.py` → 跑 `build.py`。**
规范里"可以不遵守"的地方（如结语章不设"迁移视角"小节）都在 `style-guide.md` 的"结构例外的登记"表里
显式列明，并由 `check.py` 读取——**凡是例外，都要被写下来**。
